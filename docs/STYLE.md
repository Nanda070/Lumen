# Lumen — стилистика

## Палитра

Уголь, не чёрный; красный и синий как редкие акценты, не заливка.

| Token | Hex | Use |
|---|---|---|
| `bg` | `#0C0D10` | Основной фон |
| `surface` | `#14161B` | Слои / панели |
| `surfaceRaised` | `#1A1D24` | Карточки / поля |
| `text` | `#F3F1EC` | Основной текст |
| `textMuted` | `#8A9099` | Вторичный текст |
| `accentRed` | `#C53B4A` | Сегодня, расход, серия, главный CTA |
| `accentBlue` | `#4C7CF0` | Слоты календаря, доход, выбранное, ссылки |

- Стекло: белый 6–10% + blur, волосяная обводка 8% белого
- Радиусы: 16–22
- Сетка: 8pt, много воздуха

## Движение

Гибрид **A + B**:

- База как Linear / Monarch: типографика, тишина, большие числа
- Жесты как iOS liquid glass: пружины, морфинг карточки в деталку, матовый tab bar, shared-element у события

Никакого постоянного неона и карусели на каждый тап.

## Типографика и иконки

- iPhone: SF Pro
- Финансы и даты: крупные tabular-цифры
- Иконки: один набор (Phosphor или кастомные line) — не смесь Material + Cupertino

## Layout

**iPhone — закон раскладки:** нижние табы, большие заголовки, swipe-back, haptic, safe area / Dynamic Island.

Планшет и браузер — та же система, слева узкая rail-навигация, не другой продукт.

### Табы (5 точек)

1. Today
2. Calendar
3. Tasks (сначала каркас, но в табе сразу)
4. Finance
5. More — Habits, Routine, Nutrition, Training, Settings / Backup
